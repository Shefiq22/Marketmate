# Marketmate

Food distribution and sale made easy with MARKETMATE.

## Getting Started

This is a Flutter mobile application built for Marketmate.

### Prerequisites

* Flutter SDK
* Dart SDK

### Setup

1.  Clone the repository:
    ```bash
    git clone [https://github.com/MARKETMATE-ng/market_mate.git](https://github.com/MARKETMATE-ng/market_mate.git)
    ```
2.  Install dependencies:
    ```bash
    flutter pub get
    ```
3.  Run the application:
    ```bash
    flutter run
    ```

## Project Structure
We follow a **Feature-First** architecture. Please ensure new screens are placed in the `lib/features` directory.
